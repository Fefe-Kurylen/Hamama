# Politique de confidentialité — Hamama

*Dernière mise à jour : 17 novembre 2026*

Hamama est une application mail qui fonctionne **sur ton ordinateur** et se connecte directement aux serveurs de ta messagerie.

## Données collectées
**Aucune par l'éditeur.** Hamama n'a pas de serveur à lui :
- pas de compte Hamama, pas d'inscription ;
- pas de publicité, pas de mesure d'audience, pas de traceur ;
- tes messages, contacts et réglages restent sur ton ordinateur et chez ton fournisseur de messagerie.

## Connexions à Internet
Hamama se connecte uniquement :
- **aux serveurs de ta messagerie** (IMAP pour recevoir, SMTP pour envoyer) que tu as configurés ;
- **à la base de réglages Mozilla** (autoconfig.thunderbird.net) lors de l'ajout d'un compte, pour trouver les serveurs de ton domaine (seul le nom de domaine est envoyé) ;
- **à la page de connexion de Microsoft ou Google** si tu choisis la connexion sécurisée (OAuth) ;
- **aux images distantes d'un message**, uniquement si tu choisis de les afficher (elles sont bloquées par défaut).

## Mots de passe
Les mots de passe et jetons de connexion sont **chiffrés par le système** (Windows DPAPI / trousseau macOS) et stockés uniquement sur ton ordinateur.

## Bouton « Soutenir Hamama »
Il ouvre la page de paiement Stripe dans ton navigateur. Le paiement est traité par Stripe selon sa propre politique de confidentialité ; Hamama n'a accès à aucune donnée bancaire.

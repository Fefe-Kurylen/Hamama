# ✉️ Hamama

Application mail simple, rapide et personnalisable pour Windows.

- 📥 Plusieurs comptes + **boîte unifiée** (Gmail, iCloud, Yahoo, Orange, Free, SFR, La Poste, GMX, OVH, tout serveur IMAP)
- ⚡ Nouveaux messages **en temps réel** + notifications Windows
- 🛡️ **Images espionnes bloquées**, liens vérifiables au survol, aucun script exécuté dans les mails
- ↩️ **Annuler l'envoi**, l'archivage et la suppression
- ✍️ Rédaction riche, signatures, pièces jointes par glisser-déposer, saisie automatique des adresses
- 🎨 Thèmes Graphite / Sombre / Noir OLED / Clair, couleur d'accent, 3 dispositions, densité, taille
- ⌨️ Raccourcis clavier, recherche dans un dossier ou partout
- 🔒 Mots de passe chiffrés par Windows sur l'ordinateur — rien n'est envoyé ailleurs qu'à ton fournisseur

## Construire
```
cd windows
npm install
python make-app.py
npm run dist
```
